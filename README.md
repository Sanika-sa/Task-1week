# AI Foundations & Algorithmic Projects 🚀

A curated collection of core Artificial Intelligence, machine learning foundations, and algorithmic game-playing projects implemented from scratch in Python.

## 📁 Repository Contents

1. **Neural Network from Scratch (`BasicNeural.py`)**
   - **Description:** A multi-layer perceptron built entirely using NumPy and Matplotlib (without heavy ML frameworks).
   - **Key Features:** Generates synthetic non-linear data, implements forward propagation, ReLU and Softmax activations, categorical cross-entropy loss, backpropagation, and visualizes training loss and accuracy over epochs.

2. **Rule-Based Chatbot (`chatbot.py`)**
   - **Description:** A conversational command-line assistant driven by Regular Expressions (Regex) and pattern-matching logic.
   - **Key Features:** Handles flexible user intents (greetings, project FAQs, tech stack queries, support, and exit conditions) with randomized responses and error handling.

3. **AI Tic-Tac-Toe Game (`tictactoe.py`)**
   - **Description:** An interactive command-line game where a human player competes against an intelligent agent.
   - **Key Features:** Implements the optimal **Minimax algorithm** to ensure the AI never loses, complete with real-time scoring, input validation, and clean board rendering.

## 🛠️ Tech Stack & Requirements
- **Language:** Python 3.x
- **Libraries:** `numpy`, `matplotlib`, `re`, `random`, `math`
